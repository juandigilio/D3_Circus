# The Carnival Show

Year 2000. The world ends, and the show is just getting started.
A nuclear plant explodes next to the country’s biggest circus, 
releasing a toxic cloud that turns clowns into bloodthirsty psychopaths.
In this chaotic 2D side-scroller inspired by classics like Metal Slug, 
your only mission is to escape the circus alive before the cloud reaches you. 
Run, shoot, and survive as comedy turns into horror and the show becomes a radioactive nightmare.


This is a game being developed by students from <a href="https://www.imagecampus.edu.ar/">Image Campus</a>
